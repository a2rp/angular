# JavaScript Study Notes

These are my personal study notes on JavaScript. I write and refine them while studying the language and using it to build browser applications. The notes bring core ideas, examples, and practical checks together so I can revisit what I have learned in one place.

The chapters begin with JavaScript values and control flow, then build toward functions, data structures, browser programming, asynchronous work, modules, and the language's object model. Each topic uses plain explanations and runnable examples.

## How these notes are organized

- **Core chapters** explain the language and browser concepts in a useful learning order.
- **All code samples** gathers the examples from the topic chapters in one reference.
- **Complete Q&A** records questions and clear answers across the notes.

The examples use JavaScript as the programming language. HTML appears where it is needed to show how JavaScript works with a web page. Try the examples in a browser console or a small local project, then change the inputs and observe the result.
