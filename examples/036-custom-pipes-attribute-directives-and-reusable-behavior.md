# 36. Example: Custom pipes, attribute directives, and reusable behavior

This example builds a small standalone Angular page that uses the same text-truncation logic in a custom pipe and in TypeScript. It also adds configurable hover/focus styling with an attribute directive.

## What you will build

- A pure `truncate` pipe that formats text for a template.
- A plain `truncateText()` helper shared by the pipe and component.
- An `appHighlight` directive configured by an input and bound declaratively to host events, a class, and a style.
- A standalone component that imports and uses both Angular features.

The directive only adds visual emphasis. It does not create an interaction or replace native button/link behavior.

## Start an Angular app

If you do not already have a standalone Angular app, create one with the Angular CLI and start the development server:

~~~sh
ng new angular-pipe-directive-demo --standalone --style=css
cd angular-pipe-directive-demo
ng serve
~~~

Use the generated root component as the starting point. The filenames below use the conventional `app.component.*` naming. Some CLI versions generate shorter names such as `app.*`; use the names generated by your project and make sure the bootstrapped root component points to the component you edit.

## 1. Extract the reusable transformation

Create `src/app/truncate-text.ts`:

~~~ts
export function truncateText(
  value: string | null | undefined,
  maxLength = 40,
  suffix = '…',
): string {
  if (value == null) {
    return '';
  }

  const limit = Number.isFinite(maxLength)
    ? Math.max(0, Math.floor(maxLength))
    : 0;

  if (value.length <= limit) {
    return value;
  }

  return `${value.slice(0, limit).trimEnd()}${suffix}`;
}
~~~

The helper is deterministic and has no Angular dependency. This example maps nullish input to an empty string, floors fractional limits, clamps negative limits to zero, and treats a non-finite limit as zero. When the limit is zero and the text is non-empty, the result is the suffix alone.

`String.slice()` counts UTF-16 code units, so this small example can split a combined emoji or grapheme. For strict user-perceived character limits, use a grapheme-aware policy such as `Intl.Segmenter` if the project's supported browsers and TypeScript libraries allow it.

## 2. Wrap the helper in a custom pipe

Create `src/app/truncate.pipe.ts`:

~~~ts
import { Pipe, PipeTransform } from '@angular/core';
import { truncateText } from './truncate-text';

@Pipe({
  name: 'truncate',
  standalone: true,
  pure: true,
})
export class TruncatePipe implements PipeTransform {
  transform(
    value: string | null | undefined,
    maxLength = 40,
    suffix = '…',
  ): string {
    return truncateText(value, maxLength, suffix);
  }
}
~~~

The pipe contains no duplicate transformation rules. Its `transform()` method delegates to the plain function so the same behavior can be used in a template and in component code.

## 3. Add reusable host behavior

Create `src/app/app-highlight.directive.ts`:

~~~ts
import { computed, Directive, input, signal } from '@angular/core';

@Directive({
  selector: '[appHighlight]',
  standalone: true,
  host: {
    '(mouseenter)': 'isHovered.set(true)',
    '(mouseleave)': 'isHovered.set(false)',
    '(focusin)': 'isFocused.set(true)',
    '(focusout)': 'isFocused.set(false)',
    '[class.is-highlighted]': 'isActive()',
    '[style.background-color]': 'isActive() ? appHighlight() : null',
  },
})
export class AppHighlightDirective {
  // The selector and its primary configurable input share a name.
  readonly appHighlight = input('#fff3bf');

  protected readonly isHovered = signal(false);
  protected readonly isFocused = signal(false);
  protected readonly isActive = computed(
    () => this.isHovered() || this.isFocused(),
  );
}
~~~

The directive uses the `appHighlight` input as its default background color. The host metadata listens for pointer hover and keyboard focus, toggles a CSS class, and binds the background color while either state is active. Angular updates these bindings; the directive does not reach into the DOM to set styles manually.

## 4. Import and use the pipe and directive

Replace or adapt the root component in `src/app/app.component.ts`:

~~~ts
import { Component } from '@angular/core';
import { AppHighlightDirective } from './app-highlight.directive';
import { truncateText } from './truncate-text';
import { TruncatePipe } from './truncate.pipe';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [AppHighlightDirective, TruncatePipe],
  templateUrl: './app.component.html',
  styleUrl: './app.component.css',
})
export class AppComponent {
  readonly description =
    'Angular templates can present a short preview while the full description remains unchanged in application state.';
  readonly helperPreview = truncateText(this.description, 38);
  readonly warmHighlight = '#fff3bf';
  readonly coolHighlight = '#dbeafe';
}
~~~

A standalone component must import each standalone pipe and directive used by its own template. The helper is ordinary TypeScript, so the component imports and calls it directly rather than injecting the pipe.

  <section class="panel" id="pipe-example" aria-labelledby="pipe-title">
    <h2 id="pipe-title">Format text with a custom pipe</h2>
    <p><strong>Original:</strong> {{ description }}</p>
    <p><strong>Default limit:</strong> {{ description | truncate }}</p>
    <p><strong>Custom limit:</strong> {{ description | truncate:38 }}</p>
    <p>
      <strong>Custom suffix:</strong>
      {{ description | truncate:38:' (read more)' }}
    </p>
    <p><strong>Plain helper in TypeScript:</strong> {{ helperPreview }}</p>
    <p class="note">
      The pipe and helper return a preview. The component's original
      <code>description</code> value is unchanged.
    </p>
  </section>

  <section class="panel" aria-labelledby="directive-title">
    <h2 id="directive-title">Add behavior to existing host elements</h2>
    <p>
      Move the pointer over each control or focus it with the keyboard to see
      the directive's configured color and highlight outline.
    </p>

    <div class="control-row">
      <button
        class="demo-control"
        type="button"
        [appHighlight]="warmHighlight"
      >
        Warm highlight button
      </button>

      <a class="demo-control" href="#pipe-example" [appHighlight]="coolHighlight">
        Cool highlight link
      </a>
    </div>

    <p class="note">
      These are native controls, so they keep their normal keyboard and
      activation behavior. The directive only decorates their host elements.
    </p>
  </section>
</main>
~~~

## How it works

1. `truncateText()` owns the transformation policy as a plain, deterministic function.
2. `TruncatePipe` adapts that function to Angular's template pipe syntax. Each component that uses the pipe imports it.
3. `AppComponent` also calls the helper directly for a preview prepared in TypeScript.
4. `AppHighlightDirective` matches `[appHighlight]`, accepts a color input, and binds host events, a class, and a style through `host` metadata.
5. The component imports the directive. The template applies it to native button and link elements, which retain their built-in semantics.
6. The CSS class adds a visible outline to the already focusable controls. The directive does not create clickable behavior or replace the controls' accessible names.

## Try these variations

- Change the truncation limit and suffix. Try `0`, a negative number, a fractional number, `NaN`, and a value longer than the text.
- Add a second input for a text color, or expose a sensible default for a bare `appHighlight` attribute.
- Apply the directive to a non-interactive preview paragraph and decide whether hover-only styling is appropriate there.
- Extract a different pure transformation, such as a filename formatter, into a function and wrap it in a pipe only if the template needs it.
- If the same directive behavior should always be part of one reusable component, explore composing it with `hostDirectives` as described in [Lesson 36](../lessons/036-custom-pipes-attribute-directives-and-reusable-behavior.md).

## Common problems

- **Unknown pipe or directive:** Confirm that `TruncatePipe` and `AppHighlightDirective` are in the standalone component's `imports` array.
- **The pipe does not run after changing an array or object in place:** This example accepts strings. Pure pipes also rely on changed argument values or references; prefer immutable updates for object and array inputs.
- **The original text appears unchanged in TypeScript:** That is expected. The pipe formats a template result; it does not mutate `description`.
- **The directive does nothing on an element:** Confirm the attribute selector is present and that the using component imported the directive.
- **A keyboard focus outline is missing:** Keep the `:focus-visible` rule and check that global styles do not remove outlines.
- **A truncated emoji looks unusual:** `String.slice()` uses UTF-16 code units. Use a grapheme-aware implementation if that behavior matters to the product.
